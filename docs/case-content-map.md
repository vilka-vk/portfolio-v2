# Редактура и карта кейсов

Источник навыка: gc-tilda/pishi-chelovechno, ревизия 8a644ceda63e460a94b3c2c0d884d4b057061067. Сначала подготовлен русский текст и английский эквивалент, затем эта карта, после неё HTML-композиция.

## Диагностика исходников

- Forrest: «Осуществила бесшовную миграцию» — канцелярит; «бывшими» — лишняя оценка; «В портфолио я покажу» — ненужный анонс.
- Gut Stuff: «дофамин без игровых клише» — недоказанный эффект; «никто не совмещает» — слишком общее заявление; «~80%+ (бенчмарк...)» в фактах — бенчмарк нельзя выдавать за измерение продукта.
- SayMore: «безопасный Reddit» требует раскрытия через конкретные настройки; «прогретая аудитория» — рекламный штамп; примеры с Ребеккой и Хелен не оформлены как гипотетические и удалены.
- Башня: «Так выбор UI можно привязать...» повторяет объяснение вариантов; «готовый визуальный макет» — тавтология; таблица «Для игрока / Для геймдизайна...» дублирует рассказ.
- Taromant: «soft-монетизация» и «скоуп» заменены конкретными действиями; нумерованные абзацы сведены в реальные шаги; результаты отделены от клиентской проверки.
- Trinoray: «Оптимизация логики помогла ... привлечь раунд инвестиций» — причинность не доказана; «coming soon» дублирует русский статус; объём материала не позволяет добавлять подробности исследования.

## Принципы

Только факты исходных текстов; метрики из src/content/projects.json. Заявления о медицинском эффекте, рыночные цифры без источников и вымышленные эмоции не добавлялись. Командные отзывы подписаны как командные. Числа исследований без точного подтверждения не расширялись. Сохранены исходные изображения внутри рассказа; верхние обложки не возвращены. Списки, выделения и последовательность согласованы планом, поэтому соответствующие запреты навыка применены с этим исключением.
